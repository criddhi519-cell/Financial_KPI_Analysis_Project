# Financial KPI Analysis for a Startup

## Project Overview
This project focuses on analyzing the financial performance and customer growth of a startup using Key Performance Indicators (KPIs).

## Objectives
- Analyze monthly revenue and expenses
- Calculate and analyze profit
- Study customer growth and new customers
- Analyze Customer Acquisition Cost (CAC)
- Analyze Customer Lifetime Value (LTV)
- Evaluate the LTV:CAC ratio
- Create a financial KPI dashboard using Tableau

## Tools Used
- Microsoft Excel
- Tableau Public
- CSV Dataset

## Project Files
- `Financial_KPI_Startup_Dataset.csv` – Source dataset
- `Financial_KPI_Startup_Dataset.xlsx` – Excel analysis/model
- `Financial_KPI_Analysis_Tableau1.twb` – Tableau workbook
- `LTV_CAC_Report.pdf` – LTV:CAC analysis report
- `Final_Internship_Report.pdf` – Final internship report
- `Final_Internship_Report.docx` – Editable final report

## Key Results
- Total Revenue: ₹15,19,000
- Total Expenses: ₹9,89,000
- Total Profit: ₹5,30,000
- Profit Margin: 34.89%
- Average LTV:CAC Ratio: 20.30
